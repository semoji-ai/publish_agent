# 저자 프로필 분석 차원

`/publish-profile` 스킬이 저자의 1차 자료를 분석할 때 사용하는 4개 차원별 상세 기준.

---

## 1. 문체 분석 (style.yaml)

저자의 글쓰기 방식과 언어적 특성을 측정한다.

### 어투 (tone)

저자가 독자/청중에게 말하는 방식.

| 값 | 설명 | 예시 |
|----|------|------|
| `경어체` | 일관되게 존댓말 사용 | "~합니다", "~하십시오" |
| `반말체` | 일관되게 반말 사용 | "~해", "~야" |
| `혼합` | 경어/반말 혼용 또는 문체 전환 | 설교는 경어, 청중 호칭은 직접 |
| `학술체` | 객관적·논문식 서술 | "~이다", "~라고 할 수 있다" |

**측정 방법:** 전체 문장의 어미 패턴 분석. 80% 이상 동일 어미이면 해당 유형으로 판정.

### 문장 평균 길이 (sentence_length)

한 문장의 평균 단어 수 또는 음절 수.

| 값 | 기준 (어절 수) |
|----|--------------|
| `짧음` | 평균 10어절 이하 |
| `중간` | 평균 11~20어절 |
| `긺` | 평균 21어절 이상 |

서술 시 구체적 수치도 함께 기록한다. 예: `"중간 (평균 15어절)"`

### 수사법 (rhetoric)

#### 은유 (metaphor)
직접 비교 없이 대상을 다른 것으로 표현. 빈도를 `높음/보통/낮음`으로 기록.

#### 직유 (simile)
"~처럼", "~같이"를 사용하는 명시적 비교. 빈도와 자주 사용하는 비교 대상 기록.

#### 대조 (contrast)
두 개념을 대립시켜 의미를 강조. 예: "세상의 지혜 vs 하나님의 지혜"

#### 반복 (repetition)
같은 표현이나 구조를 반복하여 강조. 어구 반복, 구문 반복 모두 포함.

#### 열거 (enumeration)
여러 사례나 항목을 나열하여 설득력을 높이는 방식. "첫째... 둘째... 셋째..." 구조.

### 비유 패턴 (metaphor themes)

저자가 즐겨 사용하는 비유 소재의 주제 영역.

예시 소재 영역:
- 자연 (빛/어둠, 씨앗/열매, 물/불)
- 여정/길 (순례, 걷기, 도착)
- 가족 관계 (아버지, 자녀, 집)
- 역사적 사건 (출애굽, 바벨론 포수)
- 일상 (식사, 농사, 건축)
- 스포츠/경쟁

분석 시 상위 3~5개 소재 영역을 추출한다.

### 논증 방식 (argumentation)

| 값 | 설명 |
|----|------|
| `연역적` | 원리/전제에서 출발하여 구체적 사례로 전개 |
| `귀납적` | 구체적 사례에서 출발하여 원리로 수렴 |
| `예화 중심` | 이야기/예화로 설득하고 원리는 함축 |
| `혼합` | 연역/귀납을 상황에 따라 혼용 |

### 단락 길이 경향 (paragraph_style)

| 값 | 기준 |
|----|------|
| `짧은 단락 선호` | 대부분 5줄 이하 |
| `중간 단락` | 평균 6~15줄 |
| `긴 단락` | 평균 16줄 이상 |
| `가변적` | 내용에 따라 단락 길이 크게 달라짐 |

## 2. 신학적 입장 분석 (theology.yaml)

저자가 주요 교리에 대해 취하는 실제 입장을 기록한다.

> **원칙:** 저자의 입장을 있는 그대로 기록하고 평가하지 않는다. "이 입장이 옳다/그르다"고 판단하지 않으며, "주류 신학과 다르다"는 식의 서술도 삼간다. 신학적 다양성을 존중한다.

### 구원론 (soteriology)

하나님의 구원 사역에 관한 이해.

기록할 내용:
- **position:** 저자가 명시적으로 취하는 입장 (예: 개혁주의, 알미니안, 웨슬리안 등)
- **emphasis:** 해당 교리에서 특히 강조하는 측면 (예: 은혜의 무조건성, 믿음의 능동성, 회개의 필요성)
- **key_texts:** 이 주제를 다룰 때 자주 인용하는 성경 본문

예시:
```yaml
soteriology:
  position: "개혁주의 — 하나님의 주권적 은혜를 강조"
  emphasis: "은혜의 무조건성, 선택 교리"
  key_texts: ["로마서 8:29-30", "에베소서 2:8-9", "요한복음 6:44"]
```

### 종말론 (eschatology)

마지막 때와 하나님 나라에 관한 이해.

기록할 내용:
- 천년왕국에 대한 입장 (전천년설/후천년설/무천년설)
- 재림과 교회의 관계에 대한 강조점
- "이미와 아직"의 하나님 나라에 대한 이해

### 교회론 (ecclesiology)

교회의 본질과 사역에 관한 이해.

기록할 내용:
- 교회의 표지에 대한 이해 (말씀·성례·권징, 또는 다른 강조점)
- 성도의 교제와 공동체성에 대한 입장
- 예배 신학 (형식, 순서, 강조점)
- 지역교회와 보편교회에 대한 관계 이해

### 성령론 (pneumatology)

성령의 사역에 관한 이해.

기록할 내용:
- 은사에 대한 입장 (은사 지속론/중단론)
- 성령의 내주와 충만에 대한 강조점
- 중생/성화에서 성령의 역할

### 성경관 (scripture_view)

성경의 권위와 해석에 관한 입장.

기록할 내용:
- 성경 영감과 무오에 대한 이해
- 해석 원칙 (문자적/신학적/역사적)
- 정경의 범위와 권위에 대한 입장

### 예정론 (predestination)

하나님의 선택과 인간의 자유의지에 관한 입장.

기록할 내용:
- 칼뱅주의/알미니안주의 등 명시적 입장
- 선택과 자유의지의 관계에 대한 강조점

### 성례론 (sacraments)

세례와 성찬에 관한 이해.

기록할 내용:
- 세례 방식과 대상에 대한 입장 (유아세례/신자세례, 침례/세례)
- 성찬의 의미와 임재에 대한 이해 (상징설/영적 임재/실재 임재)
- 성례의 횟수와 의례 방식

## 3. 설교 구조 분석 (sermon_pattern.yaml)

저자의 설교가 어떤 구조적 패턴을 따르는지 분석한다.

### 구조 유형 (structure)

| 값 | 설명 |
|----|------|
| `귀납적` | 구체적 상황/질문에서 시작하여 성경 원리로 수렴 |
| `연역적` | 본문/원리를 먼저 제시하고 적용으로 전개 |
| `내러티브` | 이야기 구조로 청중을 설교 여정에 참여시킴 |
| `주제별` | 특정 주제를 여러 본문에서 탐구 |
| `강해식` | 본문을 순서대로 해설하며 전개 |
| `혼합` | 유형을 고정하지 않고 상황에 따라 선택 |

### 서론-본론-적용 비율

각 비율은 0.0~1.0 사이 값으로 기록하며 합계가 1.0이 되어야 한다.

예시 분류:
- 서론: 청중의 주의를 끌고 주제로 안내하는 부분
- 본론: 성경 본문 해설, 신학적 내용
- 적용: 구체적 삶의 변화로 연결하는 부분

전형적인 비율 패턴 예시:
- 전통 설교: `intro 0.15 / body 0.65 / application 0.20`
- 귀납식: `intro 0.25 / body 0.50 / application 0.25`
- 강해식: `intro 0.10 / body 0.75 / application 0.15`

### 예화 빈도와 유형 (illustration_frequency / illustration_types)

**빈도 기록 방식:**
- `"본론당 1회 이하"` — 예화를 절제하는 편
- `"본론당 1-2회"` — 중간 빈도
- `"본론당 3회 이상"` — 예화 중심 설교

**유형 목록 (해당하는 것 선택):**
- 개인 경험담 (목회 경험, 성도 이야기)
- 역사적 사례 (교회사, 세계사)
- 문학/철학 인용
- 시사/뉴스 사례
- 자연 현상 묘사
- 성경 내 다른 이야기 활용

### 성경 인용 방식 (scripture_citation_style)

| 값 | 설명 |
|----|------|
| `본문 직접 인용 후 해설` | 성경 구절을 먼저 읽고 해설 전개 |
| `의역 중심` | 성경 내용을 현대어로 의역하여 설명 |
| `장절 언급 후 요약` | 참조 장절만 알리고 핵심 내용 요약 |
| `혼합` | 상황에 따라 직접 인용과 의역 혼용 |

### 청중 호칭 방식 (audience_address)

저자가 설교 중 청중을 부르는 표현.

예시: "성도 여러분", "형제자매 여러분", "사랑하는 성도님들", "여러분" 등

## 4. 어휘 패턴 분석 (vocabulary.md)

저자의 언어적 습관과 선호하는 표현을 정리한다.

### 자주 쓰는 표현 (frequent expressions)

빈도 기반으로 상위 표현을 추출한다.

기록 형식:
```markdown
## 자주 쓰는 표현

- "은혜 가운데" — 빈도: 높음
- "말씀이 선포될 때" — 빈도: 높음
- "하나님의 주권" — 빈도: 보통
```

분석 방법: 동일한 어구가 분석 대상 자료 전반에 걸쳐 반복되면 기록. 단순 조사/접속사는 제외.

### 피하는 표현 (avoided words)

저자가 의식적으로 회피하거나 자료 전반에 걸쳐 한 번도 등장하지 않는 표현.

기록 방법: 동일한 신학적 개념을 다루는 다른 저자들은 자주 쓰지만, 이 저자에게서는 나타나지 않는 표현이면 기록.

### 성경 번역본 (Bible translation)

저자가 주로 사용하는 성경 번역.

| 한국어 번역본 | 영어 번역본 |
|--------------|------------|
| 개역한글 | KJV |
| 개역개정 | NKJV |
| 새번역 | NIV |
| 공동번역 | ESV |
| 현대인의성경 | NLT |

복수 번역본 사용 시 주 번역본과 보조 번역본 구분하여 기록.

### 인용 표기 형식 (citation format)

장절 표기 방식:

| 형식 | 예시 |
|------|------|
| 약어 + 숫자 | `요 3:16`, `마 5:1-3` |
| 풀이름 + 장절 | `요한복음 3장 16절` |
| 혼합 | 본문 인용 시 약어, 참조 시 풀이름 |

괄호 사용 여부, 쉼표/콜론 구분 방식도 기록.

### 특징적 전환어/접속어 (transition words)

설교나 글의 단락 전환 시 자주 사용하는 표현.

예시:
- "그렇다면", "그런데"
- "첫째로", "더 나아가", "결론적으로"
- "무엇보다 중요한 것은"
- "이 본문에서 우리가 주목해야 할 것은"

## 분석 신뢰도 기준

| 1차 자료 수 | 신뢰도 |
|------------|--------|
| 5건 미만 | 낮음 — 경고 표시 |
| 5~14건 | 보통 — 분석 가능, 일부 항목 불확실할 수 있음 |
| 15~29건 | 높음 — 대부분의 패턴 확인 가능 |
| 30건 이상 | 매우 높음 — 신뢰도 있는 전체 프로필 |

신뢰도가 "보통" 이하인 항목은 vocabulary.md 및 각 yaml 파일에서 `# 신뢰도: 보통` 주석으로 표시한다.
