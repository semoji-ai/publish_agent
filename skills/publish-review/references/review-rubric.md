# 심사 기준표 (Review Rubric)

> **전제:** 신학적 일관성 심사는 "절대적 정답"을 기준으로 하지 않는다.
> **저자의 신학적 입장(theology.yaml)**과의 일관성만이 기준이다.
> 각 목사님의 신학적 관점 차이는 존중된다.

---

## 1. 문체 일관성 (Style Consistency)

**기준 파일:** `style.yaml` + `vocabulary.md`

확인 항목:
- 어투 (경어체/반말체 혼용 여부)
- 평균 문장 길이 (style.yaml의 `sentence_length` 대비)
- 수사법 사용 패턴 (은유, 직유, 반복, 열거 등)
- vocabulary.md의 자주 쓰는 표현 반영 여부
- vocabulary.md의 피하는 표현 사용 여부
- 성경 인용 방식 (번역본 선택, 인용 형식)
- 단락 길이 경향

| 등급 | 기준 |
|------|------|
| **A** (우수) | 어투·문장 길이·수사법·어휘가 프로필과 95% 이상 일치. 피하는 표현 미사용. 성경 인용 방식 완전히 일치. |
| **B** (양호) | 대부분 일치하나 일부 문장에서 어색한 표현 또는 피하는 표현이 1-2곳 발견됨. 전반적 문체는 저자답다. |
| **C** (보통) | 전반적 톤은 저자와 유사하나, 세부 패턴 불일치가 여러 곳 발견됨. 수정 없이는 저자의 글로 보기 어렵다. |
| **D** (미흡) | 문체가 프로필과 명확히 다르다. 어투, 어휘, 수사법에서 일관된 불일치. 문체 전반 재작성 권고. |

## 2. 신학적 일관성 (Theological Consistency)

**기준 파일:** `theology.yaml` — **저자의 입장이 기준, 절대적 교리 정답 아님**

확인 항목:
- 구원론(soteriology) 관련 진술이 저자의 입장과 일치하는가
- 종말론(eschatology) 관련 진술이 저자의 입장과 일치하는가
- 교회론(ecclesiology), 성령론(pneumatology), 성경관(scripture_view) 등 기타 항목
- 타 신학자·교단의 견해 인용 시 저자의 입장과 명확히 구분되는가
- wiki/ 기사(이전 저술)와의 신학적 연속성

> **주의:** "이 저자의 입장이 옳은가"를 판단하지 않는다.
> "이 초안이 이 저자의 기존 입장과 일관되는가"만을 판단한다.

| 등급 | 기준 |
|------|------|
| **A** (우수) | theology.yaml의 모든 관련 항목과 완전히 일관. 이전 저술(wiki/)과도 연속성 유지. |
| **B** (양호) | 대체로 일관하나 모호하거나 다소 불명확한 표현이 1-2곳 있음. 저자의 의도로 읽히지만 확인 필요. |
| **C** (보통) | 저자의 입장과 미묘하게 다른 뉘앙스가 있음. 독자가 저자의 신학적 입장을 오해할 소지가 있다. |
| **D** (미흡) | 저자의 기존 신학적 입장과 상충하는 내용이 포함됨. 저자의 입장이 아닌 다른 관점이 서술됨. |

## 3. 논리 구조 / 설득력 (Logic Structure / Persuasion)

**추가 기준 (설교·강해 문서의 경우):** `sermon_pattern.yaml`

확인 항목:
- 전제-논거-결론의 흐름이 명확한가
- 논거 사이의 비약이나 공백이 있는가
- 독자 적합성 (대상 독자에게 맞는 수준과 언어인가)
- 설교/강해 문서: 서론-본론-적용 구조가 sermon_pattern.yaml과 일치하는가
- 예화 사용이 본론을 뒷받침하는가 (sermon_pattern.yaml의 `illustration_frequency` 대비)
- 결론이 도입부 또는 주제 문장과 호응하는가

| 등급 | 기준 |
|------|------|
| **A** (우수) | 논증 흐름이 명확하고 설득력 있다. 전제-논거-결론이 유기적으로 연결. 독자 적합성 높음. |
| **B** (양호) | 대체로 논리적이나 일부 구간에서 논거 보강이 필요하거나 전환이 다소 급함. |
| **C** (보통) | 논리적 비약이 여러 곳 있음. 일부 단락의 논거가 주제 문장을 충분히 뒷받침하지 못함. |
| **D** (미흡) | 논증 구조가 불명확하거나 내부적으로 모순이 있음. 독자가 저자의 주장을 파악하기 어렵다. |

## 4. 문법 / 맞춤법 / 가독성 (Grammar / Spelling / Readability)

확인 항목:
- 맞춤법 오류 (한글 맞춤법 기준)
- 띄어쓰기 오류
- 문장 내 주어-서술어 호응
- 중복·과잉 표현
- 단락 구성의 자연스러움 (단락당 주제 집중 여부)
- 문장 길이 변화 리듬 (지나치게 단조롭지 않은가)
- 전체 분량 및 밀도 적절성

| 등급 | 기준 |
|------|------|
| **A** (우수) | 출판 즉시 가능한 수준. 맞춤법·호응 오류 없음. 가독성 높음. |
| **B** (양호) | 소수의 맞춤법 또는 띄어쓰기 오류. 가독성에 영향을 주지 않는 수준의 교정 필요. |
| **C** (보통) | 여러 곳의 문법 오류 또는 어색한 문장. 가독성을 저해하는 구간 존재. 상당한 교정 필요. |
| **D** (미흡) | 오류가 전반적으로 분포하거나 문장 구조 자체가 불분명함. 전면 재작성 권고. |

---

## 종합 판정 (Overall Verdict)

4개 차원의 등급을 합산하여 종합 판정을 내린다.

| 판정 | 조건 | 의미 |
|------|------|------|
| **PASS** | 4개 차원 모두 B 이상 | 승인. 수정 없이 또는 선택적 소폭 수정 후 다음 단계 진행 가능. |
| **CONDITIONAL** | D 없음, C가 정확히 1개 | 조건부 승인. 해당 차원만 수정 후 재심사 없이 진행 가능. |
| **REVISE** | D가 1개 이상, 또는 C가 2개 이상 | 수정 권고. 지적된 이슈를 반영한 후 재심사 실행. |

## 이슈 심각도 분류

리포트 내 이슈는 심각도에 따라 표기한다:

| 심각도 | 표기 | 의미 |
|--------|------|------|
| 필수 수정 | `[필수]` | D 등급 항목. 반영 없이는 재심사 불필요. |
| 권장 수정 | `[권장]` | C 등급 항목. 반영 강력 권고. |
| 선택 수정 | `[선택]` | B 등급 세부 이슈. 반영하면 더 좋으나 없어도 무방. |

## 재심사 체크포인트

재심사(r2, r3) 시 이전 리포트의 이슈가 해결되었는지 먼저 확인한다:

```markdown
## 이전 회차 이슈 해결 현황 (r{N-1} → r{N})

| 이슈 | 이전 등급 | 해결 여부 | 현재 등급 |
|------|-----------|-----------|-----------|
| {이슈 1} | C | 해결됨 | B |
| {이슈 2} | D | 부분 해결 | C |
| {이슈 3} | B | 미변경 | B |
```

이전 이슈 해결 현황을 리포트 서두에 포함시켜 진행 상황을 추적 가능하게 한다.
