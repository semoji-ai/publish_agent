# Publish Sermon — 설교 준비 지원

사용자의 자연어 질문 또는 성경 본문을 바탕으로 위키(KB)를 계층적으로 검색하여 설교 준비에 필요한 자료를 종합한다. 저자가 과거에 해당 주제나 본문을 어떻게 다뤘는지를 중심으로 제시한다.

## 트리거 조건

```
- "/publish-sermon"
- "설교 준비 도와줘"
- "설교 자료 찾아줘"
- "{성경 본문}에 대해 내가 뭐라고 했지" (예: "요한복음 3장에 대해 내가 뭐라고 했지?")
- "{주제}에 대한 자료 찾아줘" (예: "은혜에 대한 자료 찾아줘")
- "{주제} 설교 어떻게 했지"
- "이번 주 설교 준비해줘"
- "다음 설교 본문이 {성경 본문}이야"
```

## 사전 조건

- config.yaml 존재 (publish-setup 완료)
- wiki/ 에 기사가 존재 (publish-absorb 실행 후)
- 저자 프로필이 있으면 더 풍부한 결과를 제공하지만 필수는 아님

---

## 실행 절차

### Step 1: 사용자 질문 파악

사용자의 입력을 분석하여 질문 유형을 분류한다:

| 유형 | 예시 | 1차 검색 카테고리 |
|------|------|------------------|
| 성경 본문 질문 | "요한복음 3장 16절", "로마서 8장에 대해" | `passages/` |
| 주제/개념 질문 | "은혜에 대해", "구원론 자료" | `concepts/` |
| "내가 뭐라고 했지" | "예정론에 대해 내가 뭐라고 했지" | `sermons/` |
| 인물 관련 | "칼빈이 은혜에 대해", "루터와 율법" | `people/` |
| 혼합 | "요한복음 3장의 거듭남에 대한 내 설교" | `passages/` + `sermons/` |

질문이 모호하면 보완 질문 없이 가능한 모든 카테고리를 검색한다.

### Step 2: config.yaml 로드

`config.yaml`에서 다음 정보를 읽는다:
- `workspace` 경로
- `author.id` → `authors/{author_id}/` 프로필 경로 확인

### Step 3: 계층적 wiki/ 검색

**검색 전략 참조:** `shared/references/search-strategy.md`

검색은 3단계로 진행하며, 각 단계에서 필요한 만큼만 로드한다 (토큰 효율 우선).

#### Level 0: 카테고리 _index.md 스캔

질문 유형에 따라 아래 순서로 카테고리 `_index.md`를 읽어 관련 기사 후보를 선정한다:

**성경 본문 질문:**
1. `wiki/passages/_index.md` (본문 기사 — 최우선)
2. `wiki/concepts/_index.md` (본문과 연관된 개념)
3. `wiki/sermons/_index.md` (해당 본문 사용 설교)

**주제/개념 질문:**
1. `wiki/concepts/_index.md` (개념 기사 — 최우선)
2. `wiki/sermons/_index.md` (해당 주제 설교)
3. `wiki/references/_index.md` (외부 참고자료)

**"내가 뭐라고 했지" 질문:**
1. `wiki/sermons/_index.md` (저자 설교 — 최우선)
2. `wiki/books/_index.md` (저자 저서)
3. `wiki/concepts/_index.md` (관련 개념 기사)

각 `_index.md`에서 질문과 관련도가 높은 기사 후보 2-5개를 선정한다.

#### Level 1: 후보 기사 index.md 요약 확인

선정된 후보 기사들의 `index.md`를 읽어 상단 요약(`summary` 필드 또는 `> **요약:**` 블록)을 확인한다.

- 관련성이 확인된 기사: Level 2로 진행
- 관련 없는 기사: 제외

#### Level 2: 상세 chunks/ 로드

Level 1에서 선정된 기사 중 상세 내용이 필요한 경우에만 `chunks/`를 로드한다.

- 저자의 설교/저서 기사: 충분히 로드 (설교 준비에 직접 활용)
- 개념 기사: 저자의 핵심 입장 부분만 선택적으로 로드
- 참고자료 기사: 요약 수준만 (Level 1로 충분한 경우 많음)

**검색 결과가 없는 경우:**
```
wiki/에서 관련 기사를 찾지 못했습니다.

가능한 이유:
- 해당 주제/본문으로 아직 자료가 수집·흡수되지 않았습니다.
- 다른 표현으로 다시 질문해보세요.

자료를 추가하려면: /publish-collect → /publish-absorb
```

### Step 4: 관련 자료 종합

검색된 기사들을 다음 4가지 영역으로 분류하여 종합한다:

**4a: 저자의 과거 설교 (sermons/)**
- 해당 주제/본문을 다룬 저자의 설교 목록
- 각 설교의 핵심 메시지와 접근 방식
- 설교 날짜, 본문, 설교 구조 요약

**4b: 저자의 신학적 입장 (concepts/)**
- 해당 주제에 대한 저자의 입장 (`theology.yaml` 연계)
- 저자가 강조하는 핵심 포인트
- 관련 개념들과의 연결 (`[[위키링크]]` 기반)

**4c: 관련 성경 본문 기사 (passages/)**
- 성경 본문별 저자의 해석
- 원어/문맥 관련 참고 정보 (references/ 에서 연결된 경우)
- 연관 본문 목록

**4d: 외부 참고자료 (references/)**
- 해당 주제의 신학 논문, 주석서, 타 설교자 자료
- 저자의 설교/저술에서 인용된 참고자료

### Step 5: 설교 준비 자료 제시

종합된 자료를 설교 준비에 바로 활용할 수 있는 형태로 제시한다.

```markdown
## 설교 준비 자료: {질문/주제/본문}

---

### 저자의 과거 설교

{해당 주제/본문을 다룬 과거 설교}

| 날짜 | 설교 제목 | 본문 | 핵심 메시지 |
|------|---------|------|------------|
| 2024-04-21 | [[2024_부활절_설교]] | 요 11:25-26 | 부활 소망이 현재적 위로의 근거 |
| 2023-10-15 | [[2023_가을사경회]] | 롬 8:28-30 | 예정론과 신앙 생활의 연결 |

**설교에서 다룬 방식:**
- (주요 접근법, 예화, 적용 요약)

---

### 저자의 신학적 입장

{해당 주제에 대한 저자의 입장 요약}

- **핵심 입장:** (theology.yaml 기반)
- **강조점:** (저자가 반복적으로 강조하는 포인트)
- **관련 개념:** [[구원론]] · [[언약신학]] · [[성화]]

---

### 관련 성경 본문

{관련 본문 기사 요약}

- [[요한복음_3장]] — 거듭남과 성령의 역사
- [[로마서_8장]] — 성령의 보증과 영광

---

### 참고자료

{외부 참고자료 — reference 타입}

- (저자, 제목, 핵심 주장 한줄)
- ...

---

### 설교 준비 제안

저자의 신학적 입장과 과거 설교 패턴을 바탕으로 한 제안:

- **접근 방식:** (귀납/연역/내러티브 — 저자의 sermon_pattern.yaml 참조)
- **활용할 수 있는 예화:** (과거 설교에서 사용된 유사 예화)
- **주의할 표현:** (저자의 vocabulary.md 기반, 피해야 할 표현)
```

저자 프로필(authors/)이 있으면 설교 준비 제안 섹션을 포함한다. 프로필이 없으면 해당 섹션을 생략한다.

---

## 활용 팁

- **성경 본문이 명확한 경우:** "다음 주 설교 본문이 요한복음 4장 1-26절이야" → 해당 본문 기사와 관련 설교를 바로 찾아준다.
- **주제가 명확한 경우:** "은혜에 대한 모든 자료 보여줘" → concepts/ + sermons/ + references/ 통합 검색
- **설교 이력 확인:** "내가 로마서로 설교한 적 있어?" → sermons/ 검색 후 목록 제시
- **자료 추가 필요 시:** "이 주제 자료가 부족한 것 같아" → /publish-collect로 자료 수집 권장

---

## 참고자료 사용 원칙

위키의 `references/` 기사와 `type: reference` 원문은 목사님의 글이 아니다.

- 참고자료는 **출처를 밝힌 인용이나 요약**으로만 쓴다. 예: "○○의 『△△』에 따르면 …"
- 참고자료의 주장·해석을 목사님의 신학적 입장이나 고백, 문장으로 바꿔 쓰지 않는다.
  목사님의 입장은 `type: primary` 원고와 그로부터 만든 위키 기사에서만 가져온다.
- 문체(어미·호칭·리듬·설교 구조)는 오직 설교 팩(primary 원고 기반)을 따른다.
  참고자료의 문체를 흉내 내지 않는다.
- 참고자료와 목사님 입장이 다르면 둘을 섞지 말고, 목사님 입장을 본문으로 두고
  참고자료는 비교 자료로 밝혀 둔다.

## 설교 팩 (Sermon Pack)

`authors/{author_id}/sermon-pack.md`가 존재하면 Step 5 자료 제시에 이 팩을
**제약**으로 함께 참조한다(`custom-sermon-pack.md`가 있으면 그 파일 우선).
사용자가 이 스킬로 설교 초안/원고 전체 작성까지 요청한 경우, 초안 완료 후
기계 게이트를 돌린다 (워크스페이스에서 실행):

```
python3 "{skill_root}/shared/scripts/verify_sermon.py" <초안 파일> \
  --fingerprint authors/{author_id}/sermon-fingerprint.json \
  --rules authors/{author_id}/sermon-rules.json
```

`{skill_root}` = 이 스킬이 설치된 디렉토리 (일반적으로 `~/.claude/skills/publish-agent`;
리포에서 직접 쓸 때는 `<repo>/skills`). Windows에서는 `python3` 대신 `py -3` 사용.

`ok:false`이면 위반 목록을 근거로 재작성(최대 2회), 그래도 실패하면 남은
위반을 사용자에게 그대로 보고한다. 자료 제시 단계(설교 준비 자료 종합)만
수행하는 경우에는 이 게이트를 실행하지 않는다 — 초안이 아직 없기 때문이다.
